# AI-Driven Alumni Engagement and Career Intelligence Platform

## Overview
An AI-powered alumni networking and career intelligence platform designed to improve mentorship, resume analysis, referral management, and professional networking between students and alumni.

## Features
- ATS Resume Analysis
- AI-Based Recommendation System
- Referral Ranking System
- Alumni Networking Feed
- Role-Based Access Control
- NLP-Based Skill Extraction

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript
- Jinja2

Backend:
- Flask
- Flask-SocketIO

Database:
- SQLite

AI/NLP:
- spaCy
- Sentence Transformers
- NVIDIA Nemotron

## Installation Steps

1. Clone the repository

2. Install dependencies:
pip install -r requirements.txt

3. Run the project:
python run.py
